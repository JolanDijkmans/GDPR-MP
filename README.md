# GDPR-MP

Privacypagina voor de gesprekken van mijn masterproef (Jolan Dijkmans, Universiteit Antwerpen). Eén pagina, `index.html`, om te lezen; het akkoord zelf geven mensen in cal.com bij het boeken.

**Adres na publicatie:** https://jolandijkmans.github.io/GDPR-MP/

## Online zetten (eenmalig)

1. Zet `index.html` op `main` (merge de branch van deze sessie).
2. GitHub → Settings → Pages → *Build and deployment* → Source: **Deploy from a branch**, branch **main**, map **/(root)** → Save.
3. Na een minuut of twee staat de pagina op het adres hierboven. Zet die link in de beschrijving van het event in cal.com.

## Aanpassen

De tekst is gelijk aan het UA-formulier voor deelnemers in de Masterproef-repo (`70-ADMIN/toestemming/ua-sjablonen/UA-informed-consent-deelnemers-JD.docx`). Pas beide samen aan en zet de datum onderaan de pagina bij.

Geen cookies, geen tracking, geen externe lettertypes of scripts: een privacypagina die zelf gegevens naar derden stuurt, zou zichzelf tegenspreken.
